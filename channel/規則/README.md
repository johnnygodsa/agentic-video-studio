# 規則目錄(2026-10-22 重整後唯一有效的規則;舊檔在 `channel\_archive\`,被取代的條文在 `_archive\規則沿革.md`,只當沿革查,不照它做)

## 1. 怎麼讀:做哪一步只讀那一檔那一節(Grep 定位;指引表在 CLAUDE.md),`頻道_<名>.md` 每段開工時與對應共用檔一起讀
共用五檔只寫所有頻道一樣的規則,檔內不出現頻道名(唯一例外:`1_選題.md` 的配比表)。

## 2. 頻道覆寫機制(新增頻道只做三件事)
1. 複製 `頻道_模板.md` 成 `頻道_<名>.md`,五節標題固定(選題/文案/製作/交付發片/流程),每節只寫**與共用檔不同或共用檔要求頻道自填的**(語氣、片長、時段、BGM 曲、封面版型、字幕樣式、攻擊詞或禁用詞);共用檔已有的不重抄。
2. `CLAUDE.md` 指引表加一行:頻道名 → `規則\頻道_<名>.md`。
3. `1_選題.md` §3 配比表加一列,`pipeline\gates\specs.py FORMATS` 加片型。
衝突時**頻道檔優先於共用檔**;頻道檔裡若需要整段不同做法(例:第三頻道的動畫科普流程),放 `channel\<頻道>\` 自己的檔,頻道檔只寫路徑。共用檔要改規則時,看一遍三個頻道檔有沒有已覆寫同一條,避免改了沒效。

## 3. 寫規則的格式(改任一檔都照此)
- 只寫現在怎麼做。不寫日期、來由、使用者原話、當時數據;需要依據寫一次 `依據:_archive/<檔> §n`。試行條寫「試行至 YYYY-MM-DD 檢討」。
- 一條一個 bullet,≤2 行;例子最多一個、≤25 字、不帶片名行號。
- 門檻、順序、指令不寫規則檔,放程式與 `pipeline\docs\`;這裡只留程式判斷不了的話(角度、立場、來源、分寸、語氣、頻道差異、為什麼)。
- 同一條規則只存在一處,別處用「見 X §N」引用。新增規則前先 Grep 五檔有沒有同義條;有衝突就改舊條,不並存。
- 刪規則或改意思時,被取代的原文貼到 `_archive\規則沿革.md`(2026-10-31 瘦身的原文在 `_archive\規則_2026-10-31\`)。
- 上限:`channel\規則\*.md` 合計 ≤800 行、≤80 KB(`wc -lc`);超過就先刪再加。
