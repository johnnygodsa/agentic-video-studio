# 3 製作:素材、截圖、動畫、字幕、配音、BGM、檢查
挑素材、寫截圖規格、做動畫、配音、審 QA 圖前讀;頻道檔有覆寫以頻道檔為準。

## 1. 素材要表達那句話
- 旁白提到什麼,畫面就要有什麼;段 A 依論點清單備齊素材(每個論點 2–4 個畫面),寫稿只用備好的,寫到缺的就改句或回段 A 補。
- 素材表達不了的句子(一段時間、數量、名單、幾個問題)改用自製動畫/圖的獨立鏡頭,不拿不相干畫面墊;純感想句可用相關畫面當底。
- 講到金額、數據或具體資訊,畫面要直接秀出那個數字(數字卡、圖表、對照表,或截圖該處紅底線並放大),不可只用小字截圖帶過。
- 新片預設用新工具:文章類閱讀卡(§2)、動畫網頁渲染(§3)、指出素材某處用 kit;舊模式參數只給舊片。
- 素材上只能疊 kit(標註框、箭頭、數字彈出、下標籤),只指旁白正在講的那一處,不用光暈霓虹;數量上限 `script_lint` 擋。
- emoji、印章、拼圖、轉場不疊在素材上;自製動畫只當獨立鏡頭,句子(或合併的幾句)要比動畫長,不是有動畫就用。
- 動畫每一步在該句開頭出現;停留不足就延到下一句開頭或句後補停頓。
- 不可一閃而過:句子太短就讓鏡頭涵蓋相鄰句,不每句切一刀。鏡頭最短秒數、同圖連用、同片段與同來源上限由渲染前檢查擋(`build.py`、`--max-per-src`)。
- 某段素材種類不足先補素材再寫;同一段不連續三張同一種呈現。
- 開場 30 秒不可連續兩張以上文字卡(截圖/閱讀卡/引言卡),第一格要對標題(見 2_文案)。
- 原話用引言卡(`quote`);新舊對照用 `compare`,標籤短到不被裁。
- 引言卡上方寫誰說的(`who`,每張必填):只寫身分或職稱、不寫人名;下方出處不重複上方身分。例:「Take-Two 總裁」。
- 避開黑畫面、讀取畫面、分級、logo、字卡;偏暗提亮或換掉;黑邊裁掉;內嵌英文字幕裁出畫面或落在字幕帶後。
- 來源硬切由 build 擋;挑片段後仍看圖排除 logo 與名字卡(大字美術字偵測不到)。
- 遊戲實機畫面的英文不翻、不列已知問題;網頁截圖要翻(§2)。
- 不建跨片素材庫;泛用畫面太多就補素材或改動畫;同一篇報導依段落裁成不同的圖。
- 片段先用程式篩(`clip_scan.py`、`clips_screen.py`、`ocr_win.ps1`),每支影片只出一張低解析總覽,不逐格看;片段寫 `projects\<tag>\clips.json` + `clips_lib.py`。

## 2. 網頁截圖與閱讀卡
- 文章類預設閱讀卡(spec `mode="card"`,模板 `pipeline\templates\readercard\`),hero 圖抓不到退回純文字版。
- UI 類(價格區、推文、特殊版面)才截真實頁(`mode` 不寫):英文換繁中後截圖。
- 卡上的字全部來自原頁或譯文,不自己加字;英文一律換繁中,標「中文翻譯 · 原文:網站名」(原文是中文只寫原文網站名)。
- 暗色預設 `dark: auto`,`dark: False` 全關;舊片 `JS_DARK` 與 `assets_*_news.py` 是 legacy,不刪不改。
- 只取重點區、固定不捲動;文字類截圖與閱讀卡不傾斜,只極慢放大 + 水平漂移;傾斜只給照片/實機(`docs\build.md`)。
- 接近滿版,不可整張縮小;重點區(`hl`/`focus`)移到字幕帶以上,其餘可壓在字幕後。
- 水平不可裁到字;截圖時控制寬度、字要夠大;重點區放不下就拆兩張。
- 旁白講到的詞畫面上有就用紅底線(`hl`),不用紅框;底線在唸到該詞時畫出,`hl` 的字與旁白相同才對得上。
- 原頁沒有那句話就換圖或改引言卡標出處;不可在截圖上加字,旁白改成與畫面一致。
- 不相干又易惹議的句子用「……」截掉,不改寫原意。
- **網友帳號一律遮**(2026-11-03 使用者定案,wow_realm 起):畫面上出現網友寫的留言、評論、貼文、推文、論壇回覆、Steam 評測等,帳號名/ID/頭像一律遮掉:截圖前用 JS 把帳號字串換成 `***`(首選,不留痕跡),做不到就打馬賽克;官方帳號、媒體與公司名不遮。閱讀卡引網友話只寫「玩家留言」不寫帳號。交付前看 QA 圖逐張確認。
- 截圖:複製 `assets_TEMPLATE_news.py` 成 `assets_<簡稱>_news.py`,只填 SPECS 與 HL,不改 `news_lib.py`/`news_specs.py`;檢查項與門檻見 `pipeline\docs\assets.md`。

## 3. 自製動畫與光點背景
- 設計規格 `pipeline\ANIM_DESIGN.md`:挑類型、改模板、審動畫前先讀;[判] 是主對話判斷,使用者看過成品後修正。
- 網頁渲染 13 型,欄位見 `pipeline\docs\anim.md`;多系列、趨勢、多欄比較用 line/table/kpi/share,不硬塞長條圖。某一項遠大於其他項(>= 2 倍)想演「爆表」用 bars / cols 加 `"shock":true`(`true` = 數值最大的一項;軸暴衝,單系列,細則 anim.md §6「bars·cols 軸暴衝」;最大值 >= 次大值 3 倍時 lint 會提示)。
- 長條圖一眼分得出誰是誰:兩維度就分組加組標題;同類別同色、類別間不同色相;數值字要大(`templates\anim\tokens.css`)。
- 自製動畫鏡頭比例高於約 13%,素材數量不減。
- 自製動畫鏡頭深色底一律加光點星座背景(`--anim-bg star`);引言卡與卡片不套。

## 4. 字幕與卡片
- 規格與字型在 `build.py SUB_*`、`paths.FONT_*`。
- 字幕不留任何標點,原位置用斷行或半形空格;文案、引言卡、截圖、動畫內照常有標點。
- 拆段只切在詞與詞之間(`_split_long` + `seg.py`,詞表三層見 `docs\tts.md` §4.9);數字與量詞不拆;段首不是「的、了、嗎」;不留一兩字殘段;書名號內冒號不拆。
- 斷句審(B4):殘存接縫由 `pron-review` 判讀,通用詞進 `sub_words.txt`、本片詞進 `words.txt`。
- 卡片主字不可只有「一」「二」(像橫線),寫「問題一」「第一種」。

## 5. 配音
- 預設 CosyVoice3 參考音 B(`paths.COSY_REF`)、speed 1.18;不用語氣指令;`<strong>` 會讓語速暴衝,慎用。
- 參考音取自第三方影片,正式營利前須確認授權,交付時提醒。
- ChatTTS 只在 `--engine chattts` 或女聲;沒指名聲音就用男聲,不再問。定案音色與參考音不可動(4_交付發片 §8)。
- 女聲偏尖,渲染加 `--voice-eq soft`,不重新合成。
- 讀音表依引擎,只改送進引擎的字,字幕文案不變:
  - Cosy3:`cosy_pron.json`(詞表優先)、`pron_rules.json`(依語境,新字先加這);不用同音字替換;不可標 [zh][e]。英文 `cosy_terms.json`,不沿用 say_terms。
  - **英文人名一律送固定中文音譯**(2026-10-30 使用者定案;字幕保留英文,跨片同一寫法;全名只送姓氏,Mary Kirby→柯比,登錄 cosy_terms 附 `_asr_alias`)。廠商/品牌盡量唸中文名,台灣沒有通用譯名用中國大陸通用名(EA=藝電、BioWare=生軟);使用者指定唸英文的(Steam)照舊。
  - ChatTTS:多音字 `pipeline\tts_pron.py`、英文 `pipeline\say_terms.json`。
- 未登錄英文詞配音前擋下,主對話決定後登錄(附日期與否決寫法),不問使用者。
- 換字或新唸法用多個 seed + 辨識回查確認唸對。
- **品管項目不可減**(可改便宜跑法),對裁切後實際進片的音檔跑,項目與門檻見 `docs\tts.md` §4.1;沿用舊快取的句子也要過目前版本品管,**只在凍結前**,凍結後不因新規則重跑。
- **逗號連讀**(2026-10-31 使用者聽出 ea_me5 句 15):`comma_runon` 用完 seed 仍有 = 品管未過、改句;不可靠插入靜音過關(硬插聽起來等於沒斷)。
- 主對話與代理聽不到聲音:品管是配音唯一閘門,使用者不必聽;每版仍出優先聽清單給想抽聽時用,第一次用的唸法列唸法清單,主對話決定後登錄,不問使用者。聲碼器電音感只能靠聽。
- **E4 耳朵**(`--tts-review` 自動跑):旗標只當必聽與重錄候選,不自動擋、不自動放行;命中 `poly`/`particle` 的句子先查讀音表再決定重錄(`docs\senses.md`)。
- **連貫校正結案(2026-10-28 使用者選定)**:維持 `--comma-profile std`、`--cosy-speed 1.18`,不再請使用者聽;句群合成不做。
- 多音字診斷併入唸法清單,只換真唸錯的。
- **配音稿與讀音審(B4)**:流程在 director;配音文本與配音稿一致才打包,凍結鎖的就是配音稿(`docs\tts.md` §4.5)。
- **語境讀音記憶** `pron_memory.json`:`undetermined` 只代表測過看不出,不當通過;`rewrite` 算未決(`docs\tts.md` §4.6)。
- **C0 只補讀音,不取代全片品管**:用完整原句多 seed 試配,不切小段、不拼接音檔;辨識看不出聲調,所以無法判定不算通過,試配音檔不沿用到正式配音。
- **讀音累積表** `pipeline\pron_backlog.md`:每支片只處理命中最多的前 3 條;登 `_verified` 要有證據(使用者聽過或 `tts_pron_verify` 唸對);每月 GPU 閒時 `tts_pron_verify.py` 跑前 5 條。讀音依據 `tts_moe.py lookup <字>`;使用者已定案的(血 xiě、和 hé、關卡 kǎ)不覆蓋。

### ChatTTS
- 不用自動口語化 `[oral_N]`(會改寫句子);溫度 0.3;語助詞白名單見 2_文案 §3。

## 6. BGM
- 音量以配音為基準由 `build.py` 自動算(`audio_consts.py`)。安靜段不拉高,寧可聽不到不可蓋配音。log 警告動態大時,評論片換平穩的曲子,不硬用。
- 定案曲偏移寫在同名 `.json` 側檔;各頻道曲目見頻道檔。
- 使用者說大聲/小聲 X dB → `--bgm-db ±X`,該片之後每版都帶、寫進 handoff;改預設改 `audio_consts.py`。
- 新曲風:`bgm\ai_gen\` + `bgm-mixer`,使用者聽過再加。
- 署名見 4_交付發片 §2;Kevin MacLeod 曲只在舊片或定案曲不適用時用,挑平穩的,不給使用者試聽。

## 8. 渲染前與交付前檢查
- 渲染前檢查錯誤 0(項目見 `docs\gates_inventory.md` D 段,門檻見 `docs\build.md`、`anim.md`、`assets.md`);機械性錯誤程式自動修,只列修不了的。擋得到的不逐格看。
- 看圖才抓得到的錯、使用者看到程式該擋沒擋的錯,都寫成渲染前檢查補進本節(例:截圖切半行字、字幕帶壓字)。
- 警告不略過但只看那一格:`output\<tag>\look_<ver>.md` 列到的局部放大,主對話逐項看過並處理。
- 成片後主對話看 QA 總覽圖逐格掃「畫面有沒有在表達這句話」,沒問題才排程上片;改畫面不改稿,非改稿不可走 refreeze(2_文案 §7)。段末看 `output\<tag>\review_<ver>.md` 彙整聽/看/決定三節即可。
