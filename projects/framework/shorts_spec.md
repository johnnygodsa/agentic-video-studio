# F2-3 Shorts 直式版面規格(主對話定,2026-10-14)【判,第一支 Shorts 使用者看過後修正】

適用:ChannelA、ChannelB評論片的 Shorts(`build.py --portrait`)。ChannelC走 sci `make_film --portrait`(README §10.0),不套本檔。

## 1. 畫布與 Shorts 介面避讓
- 1080x1920、30fps。
- 介面保留區(重要文字不可進入):上 0–140(搜尋/相機圖示)、右 x>940 且 y 700–1660(按讚、留言、分享按鈕列)、下 y>1600(頻道名、標題、音樂列)。
- 文字安全框:x 80–940、y 140–1600(與 sci kit.js portrait 邊距一致)。

## 2. 版面三帶
| 帶 | 範圍 | 內容 |
|---|---|---|
| 標題帶 | y 140–250,中心 (510,195) | 鉤子大字 `hook_text`,全片常駐 |
| 畫面窗 | y 260–1340(高 1080,中心 y=800),寬 1080 滿寬 | 本鏡頭的橫式畫面,依 §3 裁切或整張 |
| 字幕帶 | 墨跡中心 (510,1420) | 字幕 |
- 底圖:同一鏡頭的橫式畫面以 cover 填滿 1080x1920,在 1/4 解析度(270x480)做模糊(boxblur 半徑約 10)再放大,亮度乘 0.45。窗外全部是這張底圖。
- 鉤子字:Noto Sans TC SubBold、白字、黑描邊 4px、右下陰影 5px(62% 黑),字級 = min(100, floor(860 / 字數)),≤ 10 字、單行、不加標點;沒給 hook_text 就不畫,標題帶只留底圖。

## 3. 畫面窗:每個鏡頭依種類決定取景(來源座標 = 橫式 1920x1080 成品鏡頭)
| 鏡頭種類 | 取景 | 窗內大小與位置 |
|---|---|---|
| 影片(`v`、`shots`) | 置中正方:取寬 cw=1080、全高;x0 = clamp(cx·1920 − 540, 0, 840),cx 預設 0.5,可由 spec.shorts 的 `cx:{"句號":0–1}` 覆寫 | 1080x1080,y 260–1340 |
| 圖片/截圖(`img`) | 文字框聯集(.boxes.json 經 layout 映到成片座標,含「中文翻譯·原文」標籤)若能放進寬 1440 且左右各留 40px:取 4:3 cw=1440,x 置中於聯集中心並夾在 0–480;否則整張 | 4:3 → 1080x810,y 395–1205;整張 → 1080x608,y 496–1104 |
| 動畫、引言卡、對比 | 整張 | 1080x608,y 496–1104 |
- 鏡頭上疊卡片(`card`)時:卡片外框(左右各加 40px)放不進上表取景寬度,就依序放寬成 1440、1920(整張),窗高同上表。
- 一律靜態取景(取景框不隨時間移動)。Shorts 的圖片鏡頭一律 `fx:none`(PLAN §3.2 不用慢放大),由 shorts 的 script 產生時寫入,build 不必特判。
- 劇透牌(spoiler)Shorts 不放;母片有 spoiler 時印警告。

## 4. 字幕(直式組,`SUB_*` 分橫/直兩組;橫式值一個都不可改)
| 項目 | 橫式(不動) | 直式 |
|---|---|---|
| Fontsize(libass 行高) | 85 | 112(全形字寬 ≈ 77.3px,×1.32) |
| 每段上限 SUB_MAX_W | 18 | 10 |
| 墨跡中心 | (960, 924) | (510, 1420) |
| 描邊 / 陰影 | 2 / 4 | 3 / 5 |
| 陰影透明度 | 60 | 60 |
- 斷句規則(不切詞、去標點、書名號冒號)照舊,只換上限。字幕段寬 + 左右 pad 必須 ≤ 860(x 80–940),超過列錯誤。
- 原規劃「×1.4」改為 ×1.32:×1.4 每段只能放 9 字,殘段變多;10 字是 860px 安全框的上限。

## 5. 節奏與長度檢查(直式模式額外,錯誤擋渲染、警告只印)
- 錯誤:總長不在 spec.shorts `len_s`(預設 25–45 秒)內;字幕段超出安全框;鉤子 > 10 字。
- 警告:任一畫面窗連續 > 5 秒(PLAN §2.4 每 3–5 秒換畫面);最後一句的原文不是以問號結尾(PLAN §2.4 最後一句問題)。
- 最短時長沿用橫式(影片 2.5、圖片 3.2、卡片 2.6、引言 3.5)。

## 6. 輸出
- 工作 tag `<tag>_<id>`(例 `dei_gamersdead_s1`);**不可用母片 tag 跑**(會覆寫母片 timeline.json/tts_qc.json)。
- 成片 `output\<tag>\<tag>_<id>_<ver>.mp4`(1080x1920,不另出 720p,< 60 秒本來就小);QA 總覽每 3 秒一格 `output\<tag>\qa_<id>_<ver>.png`。
- 配音:母片快取依文字鍵直接沿用,不重新合成;只有 Shorts 專屬新句(`<tag>\shorts_<id>.txt` 裡母片沒有的句子)才合成,合成前照 make_version 查 nvidia-smi。
