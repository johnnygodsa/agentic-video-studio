## 2. build.py
### 2.1 CLI 參數(main)
必填:`--script <script.json>` `--voice <名>` `--tag <片名tag>` `--out <檔名>`(只給檔名 -> OUTPUT/<tag>/;其他相對路徑以素材根為基準)
- 配音:`--tts-engine edge|chattts|silent`(預設 edge)、`--spk M_seed_402.pt`(chattts 音色檔名,於 SPEAKERS;自動組 tts-cmd)、`--tts-cmd`(外部指令)、`--rate +10%`(預設;定案 +18%)、`--gap 0.04`(句間秒,定案 0.12)、`--section-gap 0.15`(段間,定案 0.30)
- 素材:`--clips <json|auto>`(auto = projects/<tag>/clips_<tag>.json)、`--max-per-src 90`(定案 120)、`--media`(素材根,通常不給)
- 最短時長:`--card-min 2.6`、`--img-min 3.2`
- 混音:`--bed 0.06`(素材原聲的增益上限,0 = 不混入;每個影片鏡頭另依量到的響度壓到目標以下,見 §2.3 音訊)、`--bgm <檔>`、`--bgm-vol`(不給 = 預設「對齊配音響度」算法;給了 = 舊算法 bgm_norm × vol)、`--bgm-db`(預設算法再加減 dB)、`--voice-eq soft|<ffmpeg濾鏡字串>`(只調配音軌,不影響 TTS 快取)
- 動畫:`--anim-bg none|star`(定案 star)、`--no-anim`(不疊段落轉場)
- 範圍/模式:`--lines a-b`(只處理第 a 到 b 句,句編號從 1 起,含配音與渲染;單一數字 = 一句)、`--tts-only`(只跑配音+時間軸,寫 build/<tag>/timeline_tts.json)、`--check-only --timeline <json>`(只做渲染前檢查,不合成;含截圖文字不被畫面邊緣切到 `check_text_clip`:每個文字框在 zoom/tilt 動態全程離上緣 >= 24px 或整行在畫面外、離左右 >= 40px,數值寫進 plan.json 的 text_clip;無 .boxes.json 的圖略過)、`--check-only --timing-only --timeline <timeline_tts.json>`(T3 時長預檢,不需任何素材:缺圖/缺片段不算錯,影片鏡頭以標籤占位並照 VIDEO_SPLIT 等分;只跑 同圖連續 9 秒/2 句、鏡頭最短時長與影片上限、動畫每步秒數/停留/timeline 節點、動畫容量;跳過亮度、文字裁切、硬切、小件擺放、字幕縫、卡片、轉場與 plan.json;須與 `--check-only` 併用;`make_version --tts-review` 在配音後自動跑)、`--no-synth`(配音只准用快取)、`--force`(檢查有錯仍渲染,缺畫面除外)
**沒有**「只渲染前 N 秒」參數;要預覽部分請用 `--lines`(句為單位)。
- 直式(F2-3a,規格 `projects/framework/shorts_spec.md`):`--portrait`(輸出 1080x1920;字幕改直式組)、`--hook <文字>`(標題帶鉤子,<= 10 字,省略 = 不畫)、`--len a-b`(總長檢查秒數,預設 25-45,只在 portrait 生效)。影片鏡頭取景中心讀該句欄位 `"cx": 0-1`(只在 portrait 讀)。**不可用母片 tag 跑**。 直式時影片鏡頭上限 `VIDEO_MAX` 5 秒、等分門檻 `VIDEO_SPLIT` 4.5 秒(F2-3b,常數 `P_VIDEO_MAX/P_VIDEO_SPLIT`,main 換上;橫式維持 8 / 6.5)。

### 2.2 script.json 結構與每句欄位
頂層 `{title, sections:[{name, title?, trans?, lines:[…]}], timeline?, spoiler?, fallback?}`;`load_lines`(句編號 idx 從 1 連續編,不分段)、`load_meta`、`parse_range`。
section.trans:`wipe|title|glitch|none`(plan_trans;專案規則全片 none;title 用 section.title 或 name)。
每句欄位:
- `text` 字幕/文案;`say` 配音用(數字寫中文、英文換唸法)
- 畫面(visual_key 決定相鄰句是否共用鏡頭),優先序 anim > shots > quote > compare > img > v:
  - `v` 影片標籤(對應 clips json 的 tags);`img` 圖檔名(images/<img>.png,有 `.boxes.json` 才能 hl)
  - `shots:[{"src":"<raw檔名不含.mp4>","start":秒}, …]` 手動指定影片片段,句時長均分
  - `quote:{text,src}`(+ `img` 當模糊底圖);`compare:{left:{img,label}, right:{img,label}}`
  - `card:{big,small?}` 疊在鏡頭上的大字卡( plan_cards;連續同卡合併)
  - `anim:{type,…}` 獨立動畫鏡頭(見 §5)
- 圖片鏡頭微調:`hl:["關鍵字",…]` 紅底線(找 .boxes.json 的字,忽略空白大小寫,可跨行,同字最多標 HL_MAX=4 處;**時序**:旁白唸到該詞才畫,起點 = 該句 kws 中最早被唸到的詞的實測發音時間 − HL_WORD_LEAD 0.10s(`hl_word_time`,kw 在 text 的找法同圖上文字,經 `char_map` 換到 say,再用品管 `say_t` 取秒),不早於句子起點 + HL_DELAY 0.3s,並由後往前夾到每段至少留 HL_MIN_SHOW 1.0s 給下一段或鏡頭結束(`hl_starts`,夾完仍不早於句子起點 + HL_DELAY;橫式 `prep_hl`、直式 `make_img_p` 共用);詞不在旁白、該配音單位沒有 `say_t` 就退回句子起點 + HL_DELAY,build 印 `底線卡詞: N 段對到詞、M 段退回句首`;`--check-only` 沒有 `say_t`,該行全數退回不代表正式渲染);`focus:[x0,y0,x1,y1]`(0-1 圖片相對座標,沒 hl 時的重點區);`fx:"tilt|tilt_l|tilt_r|zoom|drift|drift_l|drift_r|none"`(預設依圖種類分兩組輪流,見下)
  - **FX 兩組(2026-10-22 PLAN_閱讀卡 #4)**:`img_kind(media, img)` 判斷圖屬 text 或 photo,`layout_shots(lines, kind_of)` 各組各自輪替。**text 組**(`FX_CYCLE_TEXT` = drift_r / drift_l 交替):極慢 zoom 1.00→`ZOOM_END_TEXT` 1.04(倍率與錨點仍由 `_zoom_fit` 依文字內容寬降倍率,drift 的 ±`DRIFT_PX` 24px 也扣進左右邊距)+ 水平漂移(整個鏡頭由 -24px 慢移到 +24px,drift_l 反向),不傾斜;走 `_zoomish` 的 2x 畫布 + `_zoom_filter`(`fx_map` 同參數,`text_clip`、版面、紅線都吃同一組),版面用平版安全線 SAFE_Y_FLAT。烤在圖上的「中文翻譯 · 原文」出處標籤也在不裁字檢查內:`_place_label` 重貼標籤時依 fx 動態把右緣內縮、上緣下移到離邊 >= TEXT_EDGE_X / TEXT_EDGE_TOP,`_label_ent` 把標籤外框當成文字框併入 `check_text_clip`(card 模式的出處在卡內底列 = DOM 文字框,本來就算)。**photo 組**(`FX_CYCLE` = tilt_l / tilt_r / zoom,與以前相同):遊戲截圖、實機照片、片段以外的非文字圖。
  - 判斷規則:`images/<img>.layout.json` 的 `kind`(`news_lib._layout_kind` 寫入:spec 明寫 `kind` > card 模式 = text > page 模式文字框面積占截圖區 > 40% = text,否則 photo)> 沒有 kind 但有 `.boxes.json` 的舊圖視為 text(舊片重渲染文字截圖也不再傾斜;要保持舊外觀加 `--legacy-tilt`,所有圖照 photo 組)> 沒有 boxes 的圖(遊戲截圖)photo。script 明寫 `fx` 優先,`drift` = drift_r/drift_l 交替。LAYOUT_VER 隨此改動換 `layout7-textdrift`,舊快取失效。
  - **補邊(2026-10-22,LAYOUT_VER `layout8-textpad`)**:drift/zoom 動態全程成片左右邊會取樣到畫布外或圖沒蓋到的底色(原本露出約 40px 黑邊)。`prep_image` 對 zoom 類走 A 法:`_zoom_pad(s)` 算動態全程超出畫布的 px(1x),`_extend_sides` 把圖左右沒蓋到處用圖最外 4 欄逐列中位數色延伸到畫布邊,畫布左右再各補 pad;`_zoom_filter` 的 perspective 四角用補邊座標、處理完 `crop` 回畫布寬(底線序列用 ffmpeg 透明 `pad_in`)。邊色逐列標準差 > `EDGE_STD_WARN` 12(非純色圖)只警告、仍逐列延伸。渲染前檢查 `check_text_pad` 驗補邊 <= `ZOOM_PAD_MAX` 96px,超過才列錯誤(補不了)。photo 組 zoom 不會超出畫布,pad = 0,行為不變。
  - **上下補邊(2026-10-22,LAYOUT_VER `layout9-botpad`)**:text 組(zoom 類)圖沒蓋到畫布底/頂時(字幕帶下方露出模糊底圖的黑帶),`_extend_vert` 在 `_extend_sides` 之後用圖最下/最上 4 列每欄中位數色延伸到畫布邊;邊色欄間標準差 > `EDGE_STD_WARN` 的那一側不延伸並警告。字幕照常疊上。
- `emo` 已停用(填了就報錯);`silent_dur` 僅 engine=silent 用
- 頂層 `spoiler:{text,dur}`:開場劇透警告牌(見 §2.4);不認得 `warn` 類欄位
- 頂層 `fallback:{"標籤":["備援標籤",…]}`:挑片段時該標籤的未用片段不夠,就依序改用備援標籤的(`load_fallback`;行為見 §2.5)

- 卡片:顯示時間只差 < CARD_BORROW 0.3 秒就滿 `--card-min` 時(常見原因:後面的 quote 向卡片底下的影片借了幾格),卡片提早出現(向前一句借時間;借的幾格不可落在獨立畫面或上一張卡片上),印「卡片 句N: … 提早 x 秒出現」。
- 摘要行(印在最後的「渲染前檢查:」那行之前;不含「錯誤」二字,make_version 仍取最後一行當摘要):`渲染前檢查自動補救: 分段 N 處 | 備援 N 處 | 重用 N 處 | 卡片提早 N 處`。分段 = 超過 VIDEO_MAX、或沒有單一未用片段夠長而分成多段的鏡頭數(含第一輪);備援 / 重用 = 段數。
- 限制:分段只做等分(不做不等長拼接);重用只限原標籤(不重用備援標籤的畫面);備援挑到的片段可能偏暗(看「挑片段 tag=…」警告);plan.json 不另外標示補救(看 log)。

## 3. script_txt2json.py(約 290 行)
`python -X utf8 pipeline/script_txt2json.py <tag>/script.txt [out.json] [--img-prefix wowi_]`(預設前綴 `re9_`!新片務必給前綴)。函式:`split_extra`、`parse`、`split_card`、`build_lines`、`main`(統計與朗讀警告:含英文/阿拉伯數字/句尾語助詞)。
語法:
- `@title 標題`;`@say 原字=唸法`(全域替換,結果寫入該句 say);`@json {…}` 併入頂層(如 `{"timeline":{"points":[[日期,說明],…],"question_between":…}}`);`@def quote:id={…}` / `@def cmp:id={…}` / `@def anim:名稱={…}`;`@spoiler [秒數|]標題|說明`
- `@fallback 標籤=備援標籤[,備援標籤…]`(可多行,一行一個標籤;同標籤後寫的覆蓋前面)-> 頂層 `fallback`(§2.5)。例:`@fallback city=trailer,leon`
- `# 段落名 [;; {json}]` 開新段落(json 併入該段,如 `{"trans":"glitch"}`);沒資料行的 # 行 = 註解
- 資料行 `標籤|字幕 [;; {json}]`(json 併入該句:hl/anim/focus/fx/shots/v…)。標籤:`xxx`->v;`img:name`->img=前綴+name;`card:大字 小字`(沿用鄰句的 v/img,行尾 `;; {"v":"標籤"}` 可改底下影片);`quote:id`;`cmp:id`;`anim`(行尾必須有 anim 欄位)
- `@def anim:名稱={…}`(不含 step)+ 句子行尾簡寫 ` ;; anim:名稱#步驟` -> 展開成 `{"anim":{…定義…,"step":步驟}}`(與內嵌寫法的 json 逐位元組相同);`#步驟` 省略就不加 step(span/stamp 等);步驟可為整數或 all/title/q;名稱不存在報錯。anim 值為字串的 json(` ;; {"anim":"名稱#2"}`)同樣展開。re9_online 已改用
- 支援的 @def 種類:`quote`、`cmp`、`anim`
- 行尾 json 的 `"f": ["F12","F13"]` = 該句對回事實核對表(`projects\<tag>\facts*.md`)的列,script.json 原樣保留;`facts_check.py` 逐句核對數字/狀態(見 `docs/facts.md`)

## 動畫網頁渲染 anim_web(2026-10-22,計畫 `PLAN_動態小件與圖表_2026-10-21.md` #1)
- **engine 欄位**:anim 定義加 `"engine":"web"|"pillow"`,省略 = web。web 但該類型還沒有網頁模板(目前只有 `bars`)或直式(`--portrait`)但不在 `anim_web.PORTRAIT_OK` 時自動退回 pillow,每型印一行 `[anim] <type> 尚無網頁模板,改用 pillow`。舊片重渲染要和以前一樣就寫 `engine: pillow`;舊 script 不用改。入口 `build.anim_engine(a)`。
- **流程**:`_anim_layers` → `_web_layers` → `anim_web.segment(a, prev, shown, title_in, n)`(逐步模式每句一段,同 step 後續句只取終態 1 格;否則整鏡一段)→ `anim_web.render(jobs)` 回傳每段 PNG 清單(RGBA straight alpha、透明底),段落播完停在最後一格。星座底(`--anim-bg star`)照舊由 `AL.over_star` 以成片絕對時間合成(模板不畫底,兩套星座不會不一致);none 疊 `AL._dark_bg()`。之後照舊 x264 成鏡頭 mp4(`build\_anim\shot_*.mp4`,簽章多帶 `web` + 模板簽章)。
- **anim_web.py 介面**:`has_template(t)`、`sig(t)`(模板 + tokens.css + gsap 內容雜湊 + VERSION)、`bars_data(...)`(定義 → 模板資料)、`segment(...)`、`render(jobs, inproc=False)`、`load(png)`;瀏覽器端 `launch / open_job / seek_shot / render_job / run_jobs`。未命中快取的段落交子行程 `python anim_web.py --jobs <檔>` 一次渲完(build 在執行緒池建鏡頭,sync Playwright 不能跨執行緒)。每段印 `[anim_web] bars N 格 X ms/格`,模板回報的版面問題印 `警告:`。
- **快取**:`build\_anim_web\<type>_<鍵>\NNNN.png` + `done`(格數);鍵 = 模板簽章 + 資料 JSON + 尺寸 + fps + 格數(格數 = min(鏡頭格數, 段長×fps 進位 + 1))。舊 `build\_anim` 不動。
- **模板**:`pipeline\templates\anim\<type>.html` 只寫 `window.build(d)`(建 `window.tl` paused,回傳 `{dur, problems}`);字型 @font-face(`paths.FONT_BOLD`/`FONT_REG`,family `AWBold`/`AWReg`)、`tokens.css`、`static\vendor\gsap.min.js` 由 anim_web 注入。確定性:只用 GSAP 時間軸,每格 `tl.pause().seek(t, false)`(第二參數必須 false,否則 count-up 的 onUpdate 不觸發);測試 `pipeline\tests\test_anim_web.py`。
- **bars 網頁版欄位**:舊 `items`/`groups`/`step`/`src`/item 第 4 欄 `{color, icon, hi}` 原樣;新增 `series:["2024","2025"]`(2–3 系列,圖例;每條數值寫 `[v1, v2]`,缺值 `null`;只有 web 支援,pillow 會報錯);多系列的 `hi` 只強調該條最後一個有值的系列:**填色維持系列色(對得上圖例)**,強調 = 2px 金色外框 + 數值字金色(單系列的 `hi` 仍是填金色)。數字 count-up、數值 ease-back 彈入;不用光暈霓虹、不循環彈跳。網頁版不跑 `AL._BarsLayout` 版面檢查(模板自行縮條厚/條距,排不下印警告;正式容量檢查在派工 #5)。
